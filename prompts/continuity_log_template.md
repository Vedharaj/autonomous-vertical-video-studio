## Invariant Checklist per Shot Cut

- [ ] **Identity Anchor:** Approved character asset(s) attached as actual ingredient(s).

- [ ] **Spatial Blocking:** Explicit left/right screen position defined for all subjects.

- [ ] **Dubbing Safety:** Zero spoken quotes or speech commands in prompt.
- [ ] **Technical Settings:** Resolution (`720p`), Aspect Ratio (`9:16`), Duration, and Model set in controls.
- [ ] **Handoff Match:** Shot $N$ ending pose matches Shot $N+1$ starting reference still.
